## 実機の準備

USB デバッグを有効にした Android 端末を接続する。初回の端末側の RSA 指紋確認を許可してから、接続を確認する。

```bash
adb devices -l

```

ネットワーク ADB を使う場合は、端末・PC・必要なら実行環境を同じ VPN 内に置き、ADB をインターネットへ公開しない。検証後はワイヤレスデバッグを無効にし、ペア設定済みデバイスを削除する。

## 実機で検証する実装済みタスク

### T6-038: 完了通知からの再開始

`PomodoroService.kt` の `ACTION_START_NEXT` を方式別に分岐済み。

1. 指定時間タイマーを完了させ、完了通知の再開を押す。設定済み時間から開始し、0 秒で再終了しないこと。
2. ポモドーロの集中・短休憩・長休憩をそれぞれ完了させ、再開で次フェーズの設定時間から開始すること。
3. 一時停止中に古い再開通知が届いた場合、残り時間を不意にリセットしないこと。
4. ストップウォッチには完了通知由来の新規計測が始まらないこと。
5. 通知タップ後、画面表示、常駐通知、音の停止が矛盾しないこと。

### T6-046 / T6-047: TalkBack とキーボード

TalkBack を有効化し、各操作が一度の読み上げで名称・状態・操作を理解でき、同じ設定に二重フォーカスしないことを確認する。

- 通知設定の朝・夜の切替と時刻ボタン
- テーマ方式、動的カラー、プリセット色
- Notion プロパティ／型の read-only 選択欄
- Plan の日付・タブ、集中方式、振り返りのタブ・期間
- タスク追加・編集の「タスク名」入力欄

外部キーボードが使える場合は、Tab 移動だけで入力、選択、保存へ到達できることも確認する。

### T6-048 / T6-049: 視認性と集計

- ライトテーマで灰・橙・黄・警告表示の文字が背景から十分に判別できること。
- 動的カラー時にも読めること。
- 振り返りの集中記録で、週合計と全カテゴリの時間・比率がグラフと一致すること。
- 長いカテゴリ名、カテゴリ数が多い場合、文字サイズ 1.3 / 1.5 / 2.0 で内容へ到達できること。
