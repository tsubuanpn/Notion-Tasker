# プロジェクト文書の方針

このフォルダーには、リポジトリを利用・保守するために必要な、長期間有効な文書だけを置きます。

* 利用者向けの導入、同期失敗時の復旧、暗号化設定の再作成、バックアップ上の制約はリポジトリ直下の `README.md` を正本とします。
* 再現可能な品質ゲートの実行結果は `VALIDATION.md` を正本とします。実行していない実機・Notion API・クラウドバックアップの検証を「成功」と記録してはいけません。
* 一時的な調査メモ、監査の作業中間物、端末固有のログ、認証情報、タスク名を含み得る資料は追跡しません。ローカルの `docs/audits/` に保存し、コミット対象にしません。

## 表示文言のスタイル

* 製品名の表示は **Notion Tasker** とする。`NotionTasker` はパッケージ名、クラス名、テーマ名などの識別子に限る。
* 利用者に見える文字列は、再利用・翻訳・書式指定が必要になった時点で `app/src/main/res/values/strings.xml` に置く。コード中の短い画面固有文言は、同じ画面に閉じ、用語と句読点をこの方針に合わせる。
* Notion のサービス名は `Notion`、日本語との間には必要な場合のみ半角スペースを入れる。画面文言の終止には原則として句点を付けない。

CI は、品質ゲートとブランド表記の基本監査を実行します。文言を追加・変更したら、対応する `strings.xml`、README、復旧手順も同じ変更で照合してください。
